BASICS
git init
create file
git add file
goes to staging area
git commit -m "Message" -> checkpoint
git status -> to check 
git log -> commit log; --oneline -> single line

BRANCHING
git branch 'branch name'
git checkout -b branch-name
...
git merge branch-name -> from parent branch
manual resolve merge conflict
git commit -> for the merge
git branch -d 'branch-name'

RESTORE
git restore . -> unstaged changes
git restore --staged . -> staged -> unstaged
git reset --soft commit_id -> commited -> staged
git reset --soft HEAD~2 -> soft reset to 2 commits back
git reset --hard commit_id -> commited -> delete
git revert commmit_id -> revert particular commit
