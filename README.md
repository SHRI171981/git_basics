# Git Basics

## Problem statement

Version control is a core engineering skill, and it is easiest to understand by doing: creating repositories, committing, branching, merging and fixing conflicts, not only by reading about them.

## Solution

A practice repository used to work through Git step by step. `steps.txt` holds notes on each command and why it is used, and the `Basics` and `Practice` folders hold the small files and scripts used to try them out, including branches and merges done through pull requests.

## Tech stack

Git, GitHub, Python (small practice scripts).

## Features

- Notes on repository setup, staging, commits, history and `git log --oneline`
- Branching and switching with `git branch` and `git checkout -b`
- Merging and resolving a bug on a branch through a pull request
- Practice scripts and journal files used as merge material

## Future steps

- Rebase, stash and cherry-pick exercises
- A GitHub Actions workflow
- Notes on branching strategies for teams

## Getting started

```bash
git clone https://github.com/SHRI171981/git_basics
cd git_basics
cat steps.txt
```
